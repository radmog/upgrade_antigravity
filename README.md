# upgrade_antigravity
Scripts de automação em Python 3 e Bash para instalar e atualizar o Antigravity (Hub) e o Antigravity IDE no Linux. Detectam arquitetura, exibem diagnósticos do sistema, comparam versões via web scraping, gerenciam versões instaladas por links simbólicos e criam atalhos de inicialização (.desktop) com feedback visual dinâmico.
